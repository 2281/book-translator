Мобильное приложение для Android. Вы загружаете книгу или любой текст, как текстовый документ, читаемый pdf, djvu, epub, fb2 итд. Приложение должно уметь считать форматы и приятно показывать отформатированный текст, как в бумажных книгах, показать на экране смартфона. Нужно хранить каталог книг. И чтобы было меню выбора книг - каталог. Настройка шрифта, размера шрифта, цвета шрифта. Но по умолчанию приятный читаемый шрифт. Возможность выбора цвета фона, выбора файла изображения для фона.
Главная особенность - это умение переводить слова с английского на русский. Делать это нужно при помощи модели https://huggingface.co/Helsinki-NLP/opus-mt-en-ru
https://huggingface.co/Helsinki-NLP/opus-mt-en-ru/tree/main

Пользователь читает английский текст, если не понимает значение и перевод этого слова, то он может нажамть на это слово на экране и ему показывается смысловой перевод этого слова на русском языке, который заменяет в тексте английское слово, на которое нажал пользователь

Нужно написать и собрать готовый .apk файл для установки на android смартфон
