# Book Translator

Читалка книг для Android с оффлайн-переводом слов английский → русский по тапу.

Читаете английский текст — встретили незнакомое слово — нажали на него —
под словом появляется русский перевод (подстрочный, как в интерлинере),
сам английский текст не меняется. Повторный тап убирает перевод.
Если слово входит в устойчивое выражение (идиому, разговорное клише —
словарь ~15 тысяч фраз), переводится смысл всей фразы и показывается
под ней целиком. Если подстрочные переводы накладываются друг на друга,
виден перевод последнего тапнутого слова. Перевод работает полностью
оффлайн, без интернета.

## Возможности

- **Форматы книг:** txt, fb2, epub, pdf (с текстовым слоем).
- **Оглавление:** если в книге есть главы/разделы (заголовки в txt,
  секции в fb2, документы spine в epub, outline в pdf), в читалке
  появляется кнопка «Оглавление» со списком глав и переходом к выбранной.
- **Каталог книг:** импорт через системный файловый менеджер, хранение
  внутри приложения, удаление, запоминание позиции чтения для каждой книги.
- **Настройки чтения:** шрифт (с засечками / без / моноширинный), размер
  12–32sp, цвет шрифта, цвет фона, фоновое изображение из файла.
  Всё применяется на лету и сохраняется между запусками.
- **Перевод слов en→ru по тапу:** двухуровневый оффлайн-конвейер.
  1) Устойчивые выражения (словарь ~15 тысяч фраз из Викисловаря + ручной
  словарь идиом) — тап на любом слове фразы переводит её целиком,
  совпадение по леммам («spilled the beans» находит «spill the beans»),
  глагол в переводе спрягается по роду местоимения слева
  («He spilled the beans» → «проболтался, выдал секрет»).
  2) Словарь слов (~86 тысяч словоформ, собран из Викисловаря) — мгновенный
  перевод одним самым подходящим вариантом с учётом грамматики: время
  («walked» → «шёл», а не «ходить»), число («door» → «дверь»),
  род по местоимению или существительному-подлежащему слева
  («She walked» → «шла», «The traveler walked» → «шёл»,
  «An old woman opened» → «открыла»). Прилагательное согласуется
  с существительным справа по роду, числу и падежу («opened the old
  wooden door» → «старую», «деревянную»). Для частых слов, где таблицы
  переводов Викисловаря неполны (woman, dog, house…), — ручные переводы
  в сборщике словаря.
  Если слова нет в словаре — под ним пишется «no translate».
  Подстрочный перевод под словом (текст не меняется), при наложении
  подстрочников на одной строке виден перевод последнего тапнутого слова.
- **О программе:** экран с атрибуцией источников (Викисловарь CC BY-SA).

## Как это устроено

### Стек

Kotlin 2.0 + Jetpack Compose (Material 3), Room (каталог),
DataStore (настройки), minSdk 24 (Android 7.0+).

### Перевод

Перевод — **только словарный** (мгновенно, без нейросети и интернета).
Словарная база
SQLite (~15.6 МБ в assets) собирается скриптом `tools/wiktionary/build_dictionary.py`
из машиночитаемой Викисловаря [kaikki.org](https://kaikki.org) (CC BY-SA):
~86 тыс. словоформ с грамматическими тегами и переводами, ~15 тыс. фраз
(идиомы, клише), ~35 тыс. русских существительных с родом. Формы прошедшего
времени русских глаголов хранятся с родами («шёл|шла|шло|шли»),
прилагательные — с парадигмой («старый|старая|старое|старые|старую»):
род/число/падеж выбираются по контексту предложения (местоимение или
существительное-подлежащее слева, существительное справа). При открытии
книги из базы в память грузится только словарь слов этой книги (пара МБ),
фразы — целиком. Обновление базы на устройстве — по `user_version`
из заголовка SQLite.

(До версии 0.7.0 в приложение была встроена нейросетевая модель
Helsinki-NLP opus-mt-en-ru — убрана как избыточная: словарный перевод
точнее и на порядки быстрее.)

### Архитектура

Все форматы книг приводятся к единому внутреннему представлению
(`BookContent` — название + главы + абзацы), поэтому читалка и перевод
не зависят от формата:

- `parse/` — парсеры: `BookParser` (диспетчер + txt), `Fb2Parser`
  (XmlPullParser), `EpubParser` (ZIP + OPF/spine + XHTML, без зависимостей),
  `PdfParser` (PDFBox-Android, извлечение текстового слоя).
- `model/` — словарный перевод: `WordDictionary` (провайдер базы +
  словарь книги в памяти, род русских существительных), `DictionaryLookup`
  (выбор перевода с учётом времени/рода, эвристика местоимения и
  подлежащего, согласование прилагательных), `IdiomDictionary`
  (лемматизированный поиск фраз).
- `data/` — Room (`BookEntity`), `BookRepository`,
  настройки на DataStore.
- `ui/` — экран каталога (в т.ч. «О программе») и экран чтения
  (интерлинер `InterlinearParagraph`, оглавление с переходом к главам,
  панель настроек).
- `app/src/main/assets/dict/` — словарная база SQLite (собирается
  `tools/wiktionary/build_dictionary.py` из дампов kaikki.org).

Подробнее: план по этапам — `ROADMAP.md`, правила для агентов — `AGENTS.md`.

## Сборка

Готовый APK последней версии лежит в корне репозитория
(`book-translator-vX.Y.Z.apk`) — его можно сразу ставить на смартфон,
ничего не собирая. Ниже — как собрать APK самостоятельно с нуля.

### Шаг 1. JDK 17

Нужен JDK 17 (например, OpenJDK). Проверка:

```bash
java -version   # должно быть 17.x
```

Ubuntu/Debian: `sudo apt install openjdk-17-jdk`.

### Шаг 2. Android SDK

Вариант А — установить Android Studio: SDK ставится вместе с ней,
файл `local.properties` с `sdk.dir` создаётся автоматически при
открытии проекта.

Вариант Б — только командная строка:

```bash
# Скачать command line tools с https://developer.android.com/studio#command-tools
# и распаковать, например в ~/Android/Sdk/cmdline-tools/latest
export ANDROID_HOME=~/Android/Sdk
yes | $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager --licenses
$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager \
    "platform-tools" "platforms;android-35" "build-tools;34.0.0"
```

Затем в корне проекта создать `local.properties`:

```
sdk.dir=/home/<user>/Android/Sdk
```

### Шаг 3. Сборка APK

```bash
git clone https://github.com/2281/book-translator.git
cd book-translator
./gradlew assembleDebug
```

Первая сборка скачает Gradle и зависимости (~1–2 ГБ, нужен интернет),
дальше сборки инкрементальные и быстрые. Результат:

```
app/build/outputs/apk/debug/app-debug.apk   (~33 МБ, словарная база внутри)
```

Debug-APK подписан отладочным ключом и сразу пригоден для установки.
Release-сборка с собственным ключом подписи — на этапе 5 (см. ROADMAP.md).

### Шаг 4. Установка на смартфон

По USB с включённой отладкой:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Или скопируйте APK на смартфон любым способом (USB, мессенджер, облако),
откройте файл и разрешите установку из неизвестных источников.

При первом открытии книги словарь её слов загружается в память за пару
секунд, дальше перевод по тапу мгновенный. Приложение в установленном
виде занимает ~50 МБ.

## Проверка без сборки

В `samples/` лежат тестовые книги во всех поддерживаемых форматах
(`sample-en.txt/.fb2/.epub/.pdf`, `sample-idioms-en.txt` — для проверки
идиом, `sample-chapters-en.txt` — для проверки оглавления) — удобно
для первой проверки импорта и перевода.
